# OpinionSearch 面试基础站

面向已有 Agent 基础、需要吃透本项目的面试准备站点。主线是舆情 Agent 的运行（AgentLoop 与失败分支），基础设施只作为保证运行可靠的支撑；概念速查放在附录。

与现有的 `opinion_search_interview_guide/`（14 模块深度课程）分工：本站是**入门层**，帮你先读懂概念；每页底部的“深入阅读”会指向深度课程和 `docs/interview/` 中对应的完整资料。

## 打开方式

无构建依赖，直接用浏览器打开 `index.html`，或在本目录启动静态服务：

```bash
python3 -m http.server 8800      # 在 opinion_search_foundations/ 目录下
# 打开 http://127.0.0.1:8800
```

## 目录结构

```text
index.html                 入口；按顺序加载脚本
css/site.css               样式
js/svg.js                  SVG 节点与连线生成器
js/site.js                 页面注册表与共享工具（先于页面加载）
js/app.js                  路由、侧栏、上一页/下一页、深入阅读链接
js/data-code-map.js        代码地图数据（由脚本生成，勿手改）
js/pages/*.js              五组页面内容
scripts/gen_code_map.py    从 opinion_search_agent/src 重新生成代码地图
scripts/browser_smoke.mjs  浏览器交互冒烟测试（需要本地 Chrome 的远程调试端口）
```

## 维护约定

- 代码地图的行数和文件清单来自仓库。仓库结构变化后，运行 `python3 scripts/gen_code_map.py` 重新生成。
- 站内的代码事实（阶段名、错误类型数量、熔断阈值、存档边界名等）已对照代码核实。改代码后，先更新对应页面再发布。
- 页面中的“模拟器”（熔断、预算、回放篡改）是对算法规则的教学模拟，不是真实运行，页面中已标注。
- 数字必须带口径。新增数字时，同步在“数字口径”页补充测量方式与日期。

- 截图人工检查了总览、组件接线、数据流、状态机、恢复、工具、回放、上下文等图形页面，并修正了标签溢出与遮挡问题。

## 已知限制

- 站点本身不做任何数据采集，也不依赖网络；字体使用系统字体。
- 问答库中的“深挖”题只给出参考方向，最终答法需要结合自己的理解组织。
- 站内数字以本次实测和仓库文档为准。不同时间的测试数会变化，面试时请以当场实测为准。
