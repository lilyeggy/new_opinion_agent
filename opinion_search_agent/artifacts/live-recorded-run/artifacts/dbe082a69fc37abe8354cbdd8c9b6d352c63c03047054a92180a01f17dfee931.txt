# 三九胃泰中秋广告文案「求别团圆」致公关灾难 华润三九急撤下宣传

临近中秋佳节，内地老牌胃药「三九胃泰」近日推出的一则线下宣传广告却引发轩然大波。该品牌以「三九胃泰求『你们』中秋别团圆了」作为巨幅宣传口号，被大批网民怒轰公然冒犯华人重视团聚的节日情感，迅速登上网络热搜。涉事品牌母公司华润三九医药股份有限公司于9月15日紧急回应，承认相关广告由总部策划，接获投诉后正陆续安排全线撤除广告。

## 大字博眼球小字免责

综合内地媒体报道，涉事广告海报在显眼位置用特大字体写上「求『你们』中秋别团圆了」，仅在左下角以不起眼的小字附注，澄清「你们」是指高油高糖的月饼、冰饮及重口味菜肴，本意为提醒市民别让这些伤胃食物在胃部「团圆」。翻开内页亦仅标注「月饼和冷饮不要在胃里团圆了」。然而，大批公众对这种「大字撩拨情绪、小字推卸责任」的营销套路极为不满，痛斥品牌企图利用「反节日」的认知冲突博取眼球，缺乏对社会公序良俗与传统文化的起码尊重。

## 七夕曾推「劝分手」屡试边界惹反感

事实上，这并非三九胃泰首次采用此类争议手法。今年七夕情人节期间，该品牌亦曾在重庆等地刊登「劝你们和平分手」的广告，随后才解释是要「火锅配冷饮」等伤胃饮食组合「分手」。评论指出，品牌反复利用公众情感打擦边球，已严重透支消费者的好感与信任。

市场分析指，该品牌的激进行销背后反映出深层的业绩焦虑。财报显示，华润三九2025年销售费用高达90.89亿元人民币，市场推广费逾50亿元；惟其健康消费品板块今年上半年营收按年大幅倒退23.3%，三九胃泰在内地中成药胃药市场的排名亦跌出前三名。分析认为，面对销售收缩压力，品牌急于「出圈」无可厚非，但以冒犯大众情感换取短期流量，长远只会进一步损害老字号品牌的信誉资产。

## 网民留言：

*   「每次都是同一套路，七夕叫人分手，中秋叫人不要团圆，事后才在角落以蚂蚁般细小的字体解释是指食物。此等做法只属小聪明，并非创意，只会令人反感。」
*   「堂堂上市国企，每年投入五十多亿元进行市场推广，构思出来的文案水平竟如此低落。如今演变成全网抵制，堪称公关灾难的典范。」
*   「胃药本应帮助人们舒缓胃痛、开开心心吃一顿饭，如今竟制作这等添堵的广告，看见也觉得胃痛，日后购买胃药定必避开这个品牌。」
