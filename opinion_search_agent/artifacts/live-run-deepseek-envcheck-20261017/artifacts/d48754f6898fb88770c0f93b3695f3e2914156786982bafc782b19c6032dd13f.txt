# 2026年国庆档电影总票房11.65亿元

来源：[光明网-《光明日报》](https://epaper.gmw.cn/gmrb/html/content/202610/09/content_26874.html)2026-10-09 05:30

[](https://news.gmw.cn/2026-10/09/content_39035783.htm)[X](javascript:;)[](https://news.gmw.cn/2026-10/09/content_39035783.htm)

**光明日****报北京10月8日电（记者李笑萌 通讯员王子娇）**根据国家电影局统计，2026年国庆档电影票房为11.65亿元，连续7天每日票房破亿元，观影人次共3199.59万。其中，影片放映场次为329万场，同比增长2.21%；平均票价为36.41元，较去年同期降低0.28元，同比下降0.77%；国产影片票房占比为78.7%。《神探之痕迹》《什么意思夫妇》《生化危机：爆发夜》《欢迎来龙餐馆》《小猪佩奇·完美假期》位列档期内票房前5名。截至10月7日，全年电影总票房为307.46亿元，观影人次7.84亿。

今年国庆档上映影片涵盖悬疑、现实、喜剧、动作、亲子等多个类型，不同圈层的观众都能够找到适合自己的影片。《神探之痕迹》取材于“七一勋章”获得者、痕迹检验专家崔道植的经历，以刑事技术警察数十年的职业坚守为叙事主线，上映首日票房占比接近四成，截至10月7日票房达4.23亿元。《什么意思夫妇》把镜头对准一对处在“离婚冷静期”的中年夫妻，借灵魂互换的喜剧设定，讲述二人重新看见彼此的故事，上映后日票房稳步走高，以2.44亿元票房位列档期第二。

国庆假期，全国各地推出“电影+”跨界融合活动。山东青岛开通“青岛电影”地铁号并发布4条“跟着电影游青岛”主题旅游专线，市民和游客可循着镜头光影打卡取景地。辽宁康平县在辽街特色街区安排了七天八夜的公益电影，搭配美食与夜游，打造文体旅融合新场景，让县域游客白天观光、晚上观影。小小的电影票根被赋予了更多用途，凭它出行、用餐、看展、观赛，观影之外的消费场景被逐一打开。广西柳州联合全市80家影院、书店、景区、酒店推出票根全域优惠。在江西吉安，观众持当天电影票根走进参与活动的店铺，可免费兑换特色小吃、享受专属优惠。一张票根在影厅里是两个小时的故事，在影厅外则成为一整个假期的烟火。

《光明日报》（2026年10月09日 09版）
