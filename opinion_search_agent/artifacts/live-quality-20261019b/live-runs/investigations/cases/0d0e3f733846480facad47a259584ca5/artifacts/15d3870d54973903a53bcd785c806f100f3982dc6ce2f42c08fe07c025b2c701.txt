# 陈醋冰淇淋？野人先生丰收节5款新品实测，附快闪薅羊毛攻略

源自128位全网作者

10-17 19:19

9月中旬那波"难吃"风波，大家看完热闹就散了，但[野人先生](https://pinpai.smzdm.com/488102/)的回应方式有点特别：不辩解、不对线，四天后发了一封感谢信，顺手官宣了9月23日启动的**"冰淇淋丰收节"**，口号叫"与大地共丰收"。五款新品全是把田间秋收风味做成冰淇淋。这个秋天一直在卖，还以快闪巡礼的形式逛商场，小红书话题今天还在刷屏。哪款值得吃、快闪怎么玩、怎么买最省，我一次盘齐。微博 小红书

**五款丰收新品，先给一句话结论**：[大米](https://www.smzdm.com/fenlei/dami/)、芝麻开花、金秋南瓜、麻辣[花生](https://www.smzdm.com/fenlei/huasheng/)、红高粱老陈醋，官方合集帖和高赞实测帖都对得上号。单杯28元，分时现蒸，每款一句话：小红书 小红书

*   **大米**：招牌常青款，[每日](https://pinpai.smzdm.com/62008/)现蒸、嚼得到米粒，清淡不齁甜；"第一次吃推荐哪个"是评论区问得最多的问题，最高赞答案就是它。小红书

*   **芝麻开花**：香得很"沉"，像固体版黑[芝麻糊](https://www.smzdm.com/fenlei/zhimahu/)但不腻，石磨低温研磨的芝麻给足了底气。小红书

*   **金秋南瓜**：贝贝南瓜早上现蒸，五款里"低糖不甜"共识度最高，暖橙色出片，怕甜的选它。

*   **麻辣花生**：本次惊喜担当，先麻后辣、辣味柔和，花生酥香叠咸甜，评论区直接分成"上头党"和"啥玩意党"。

*   **红高粱老陈醋**：争议之王，陈醋配奶香、酸甜解腻垫着高粱粮香，亲测者说"饺子蘸醋加奶味"；好不好吃因人而异，**建议先免费试吃**。
