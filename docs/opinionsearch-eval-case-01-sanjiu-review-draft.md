## 4. 典型错误候选：先决定如何评分

1. **对象错位：**调查同一品牌的另一次广告事件，而非此中秋广告。
2. **来源升级：**把 S1/S6 转述的工作人员回应写成已查到品牌原始公告。
3. **进展升级：**把“安排撤下”或“通知下刊”写成“所有广告已经撤除”。
4. **观点泛化：**把某篇评论或少量网友看法写成“绝大多数公众认为”。
5. **凭空补齐：**没有核实的材料仍写出确定的监管结论、传播规模或品牌后续承诺。
6. **引用不支持：**给出可点击链接，但链接摘录无法支持所写判断。

这些是候选错误类型，不是这一次 Agent 的评测结果。每项严重程度、是否必须一票否决、如何统计，均待共同决定；目前不设通过率和总分。
