## 1. 顶层速查

```text
opinion_search_agent/
├── README.md                      项目定位 / 运行方式 / 实测结果 / 已知限制
├── pyproject.toml                 依赖声明
├── archive/harness-pipeline/      已归档的多角色流水线（只读参考）
├── src/opinion_search/            源码（91 个 py 文件，约 20.6k 行）
└── tests/                         测试（89 个文件，约 18.8k 行）
```

**依赖方向**（严格单向，不要记错）：

```text
入口 → 组合根 → 领域 → Runtime → 支撑
```

| 目录 | 层 | 知道"舆情"吗 |
|---|---|---|
| `runtime/` | L1–L3 | **不知道** |
| `domain/opinion/`、`domain/investigation/` | 应用层 | 知道 |
| `context/`、`memory/`、`tools/`、`models/` | 支撑 | 部分知道（`catalog.py` 依赖 opinion 的 `ClaimStatus`） |
| `app/`、`investigation/`、`web/` | 组合根 / 入口 | 知道 |
